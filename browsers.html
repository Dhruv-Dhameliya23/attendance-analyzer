Frequently Asked Questions about Browser Support

Why does Attendance Analyzer require a Chromium-based browser?

The extension is engineered on modern Manifest V3 Chrome Standards, taking full advantage of the Chrome Side Panel API, client-side isolated background service workers, and local indexed storage. Chromium powers over 75% of desktop browsers worldwide, ensuring maximum speed and privacy.

Can I use Attendance Analyzer on Mac (Apple Silicon M1/M2/M3/M4 or Intel)?

Yes, 100%! You can install and use Attendance Analyzer on macOS using Google Chrome, Brave Browser, Microsoft Edge, Arc Browser, Opera, or Vivaldi. All calculations run with high-performance native ARM64 speed.

Can I install the extension on an Android phone?

Standard Google Chrome on Android does not support desktop extensions. However, you can download Kiwi Browser from the Google Play Store on Android, which provides a native extension bridge to install Attendance Analyzer directly from the Chrome Web Store.

What happens to my data if I uninstall or switch browsers?

All attendance calculations, targets, and simulated concessions are stored 100% locally in your browser's private indexed sandbox. If you uninstall the extension, the browser immediately wipes its local database with zero cloud footprint.
